# Changelog — версия 0.8 patch expanded

## Тип обновления

Obsidian Patch Pack / точечный пакет правок.

## Что добавлено

- Расширен файл `04_Сюжет/План глав 1-5 — подробный разбор.md`.
- В каждую из глав 1–5 добавлены подробные эпизоды.
- Для каждой главы прописаны:
  - функция главы;
  - повествование;
  - локация;
  - главные элементы;
  - последовательность эпизодов;
  - эмоции и конфликты;
  - что нельзя раскрывать слишком рано;
  - итоговые смыслы главы.

## Что уточнено

- Глава 1: голос Ника, витрина с лошадкой, финал на мысли о неправильном предмете.
- Глава 2: перспектива Мираны, эксперимент в мастерской, старушка-травница, первая запись о Нике.
- Глава 3: старый справочник/травник как первая книга Ника.
- Глава 4: одеяло выменяно за хлам, узор на одеяле как скрытый будущий контур, первые проявления одеяла.
- Глава 5: главные аномалии эпизода — Кусок тихого дерева и Маленький осколок нижнего неба.

## Что не трогалось

- Старые заметки проекта не изменялись напрямую.
- Новые отдельные заметки для каждого эпизода не создавались.
- Глобальные тайны мира не раскрывались в ранних главах.
