# Версия 0.7 patch — структура первой книги и финальные аномалии

Дата: 2026-05-22  
Тип обновления: **Obsidian Patch Pack**

## Добавлено

- Добавлен план первой книги на 26 глав + эпилог.
- Добавлена писательская система первой книги: жанр, тон, повествование, формула глав и приёмы.
- Добавлена отдельная карточка аномалии [[Ложка лишнего вкуса]].
- Добавлена отдельная карточка аномальной местности [[Зеркальная трава]].
- Добавлены инструкции для ручного PATCH UPDATE без пересборки всего архива.

## Изменено / уточнено

- Первая книга строится через постепенное расширение пространства: кроватка → дом → мастерская → теплица → Холвид → храм → торговец → мастер → граница → город.
- К концу первой книги Нику 6 лет.
- Первая сдаваемая аномалия — [[Ложка лишнего вкуса]].
- В 14-й главе Ник сам относит ложку в храм, оставляет надпись мелом на полу и не выдаёт себя.
- Финальная аномалия — [[Зеркальная трава]], где Ник спасает отца через понимание задержанной логики движения.

## Не трогалось

- Скрытый сюжет сервера и операторов.
- Глобальные тайны храмов.
- Спонсоры и выкуп душ.
- Ранние эпизоды сохраняются без переписывания.

## Требует решения

- Точный текст надписи Ника мелом на полу храма.
- Возрастная разметка каждой главы по месяцам/годам.
- Точный момент появления отдельных выбранных аномалий: свеча, пуговица, перо, сухарь.
